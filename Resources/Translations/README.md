# Auxiliary-language data

Each JSON file is keyed by the official question ID. Every record contains a question, four choices in the same original-index order as the English pool, and a substantive explanation. `en.json` repeats the official English question and choices for schema consistency; the UI suppresses those duplicates and shows only its English explanation.

English in `questions.json` and its official answer mapping remain authoritative. These translations are unofficial learning aids.
